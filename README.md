# Gym Tracker

A weekly gym planner and progress tracker. Log your workout plan, record sets, and track progress over time.

## Tech stack

- **React 19** with **TanStack Start / Router**
- **Tailwind CSS v4** via Vite plugin
- **shadcn/ui** components (Radix primitives + CVA)
- **Recharts** for progress charts
- **npm** as the package manager

## Getting started

```sh
git clone <this-repository-url>
cd gym-tracker
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

## Environment variables

Create a `.env` file in the project root:

```
VITE_SUPABASE_URL=
VITE_SUPABASE_ANON_KEY=
```
